# premiere-pr

Dépôt d'entraînement pour ma première pull request.

## Objectif

Ce dépôt sert à pratiquer le flux de travail GitHub de base, sans risque :

1. Créer une branche
2. Faire une petite modification
3. Pousser la branche sur GitHub
4. Ouvrir une pull request (PR)
5. La relire, puis la fusionner (*merge*)

## Commandes utiles

```bash
# Créer une branche et s'y placer
git checkout -b ma-branche

# Enregistrer ses modifications
git add .
git commit -m "Décrire la modification"

# Envoyer la branche sur GitHub
git push -u origin ma-branche

# Ouvrir une pull request
gh pr create
```
